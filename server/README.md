# AI Studio Lab — Серверный API для Android

Безопасный серверный бэкенд на **Node.js** с использованием официального пакета **`openai`** и **OpenAI Responses API** (`gpt-5.6-sol`).

## 🔒 Безопасность
- API-ключ `OPENAI_API_KEY` хранится **исключительно** на сервере в переменных окружения (`.env` или системных переменных).
- Ключ никогда не передаётся в клиентское Android-приложение и не компилируется в APK.
- Включен CORS для обращений от мобильного клиента.

## 🚀 Установка и запуск

1. Перейдите в папку сервера:
   ```bash
   cd server
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   И укажите ваш реальный `OPENAI_API_KEY`.

4. Запустите сервер:
   ```bash
   npm start
   # Или в режиме разработки с автоперезапуском:
   npm run dev
   ```

Сервер начнет слушать порт `3000`.

## 📡 API Endpoints

### 1. `POST /api/chat`
Основной endpoint для общения с моделью.

**Запрос:**
```json
{
  "message": "Привет! Напиши краткое объяснение корутин в Kotlin",
  "previousResponseId": null
}
```
*Если это продолжение беседы, передайте `responseId` предыдущего ответа в `previousResponseId`.*

**Ответ (HTTP 200):**
```json
{
  "text": "Корутины в Kotlin — это легковесные потоки...",
  "responseId": "resp_abc123xyz"
}
```

### 2. `GET /api/health`
Проверка статуса сервера.

## 📱 Подключение из Android

- **В Android Эмуляторе**: используйте `http://10.0.2.2:3000/api/chat` (IP `10.0.2.2` автоматически перенаправляет на `localhost` хост-машины).
- **На реальном устройстве**: укажите локальный IP вашего компьютера (например, `http://192.168.1.50:3000/api/chat`).
- В самом приложении есть удобное окно настроек сервера с проверкой доступности и историей сессий.
